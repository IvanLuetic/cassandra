# Cassandra

Projekt za vježbu iz Cassandre za kolegij Upravljanje Podacima.

## Pokretanje

```
docker compose up -d
```
## Spajanje na Cassandru

```
docker exec -it cassandra-cassandra-1 cqlsh
```

## Struktura

- screenshots - screenshots rezultata svakog zadatka
- ODGOVORI.md - Odgovori na pitanja iz zadataka
- docker-compose.yaml - Konfiguracija projekta
- queries.cql - Svi korišteni upiti
